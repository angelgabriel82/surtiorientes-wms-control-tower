## 📦 Contenido Principal del Repositorio Remoto
1. **`Documento_Tecnico_Investigacion.md`:** Documento científico y técnico completo con el marco teórico, formulaciones matemáticas (Magnus-Tetens, $Q_{10}$, Min-Heap), arquitectura y manual de usuario.
2. **`app_jefatura.py`:** Aplicación funcional en Python/Streamlit para la Torre de Control WMS con gestión de inventario, clasificación ABC, FEFO y copias de seguridad SQLite.
3. **`Dashboard_surtiorientes.html`:** Dashboard web monolítico reactivo en HTML5/Vanilla JS sin dependencias de servidor.
4. **`Repositorio/`:** Subcarpeta con el paquete modular para ejecución rápida (`app_jefatura.py` y `requirements.txt`).
5. **`Base_de_datos/`:** Base de datos relacional SQLite con modo WAL y catálogo maestro SSOT de 871 SKUs reales de Inversiones Surtiorientes.
6. **`Scripts_Python/`:** Microservicios algorítmicos para simulación bioclimática diurna, árboles de decisión de muelle y colas Min-Heap.
7. **`Documentos_Entregables/`:** Diagramas BPMN 2.0 (As-Is / To-Be), DFD Niveles 0, 1 y 2, y evaluación de viabilidad financiera (ROI y Payback).
